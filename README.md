# Taller #3 - Sumador Completo en Verilog

## Descripción del problema
Se implementa un sumador completo en Verilog que calcula
la suma de 2 bits más un carry de entrada (Cin), mostrando el resultado
en binario en pantalla.
El circuito recibe 3 entradas (A, B, Cin) y produce 2 salidas (Sum, Cout).
 

## Retos afrontados
- Entender como funciona Verilog, no estaba familiarizado con un lenguaje parecido a este 
- Comprender la lógica del carry de salida (Cout), que requiere evaluar
  todas las combinaciones donde dos o más entradas son 1.

## Conclusiones
- Verilog es un lenguaje que no va enfocado a programar sino a decscibir como se comportan los componentes de un circuirto. 
- El sumador completo es un circuito fundamental en la electrónica digital,
  ya que es la base de operaciones aritméticas más complejas como sumadores
  de 8, 16 o 32 bits.
